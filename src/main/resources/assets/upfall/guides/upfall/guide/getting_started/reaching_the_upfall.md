# Reaching the Upfall

The only way in is the **Halo Portal**: a frame of <ItemLink id="halo_frame" /> lit by a <ItemLink id="skyward_key" />, built high in the Overworld sky.

## Halo Frame

<Row gap="10">
  <BlockImage id="halo_frame" scale="4" />
  <RecipeFor id="halo_frame" />
</Row>

One craft gives 8 frames and costs a Netherite Ingot, so plan the portal size before crafting. Halo Frames are the only block that works for the frame.

## Skyward Key

<Row gap="10">
  <ItemImage id="skyward_key" scale="4" />
  <RecipeFor id="skyward_key" />
</Row>

The key needs an Elytra and a Nether Star. It is **consumed** when it lights a portal (creative mode excepted).

## Building the portal

1. Fly or build **above Y 200** in the Overworld. The key stays silent below that and tells you so; it does nothing in any other dimension.
2. Build a rectangular frame out of Halo Frames, like a Nether portal. Corners are not needed.
3. Right-click the inside of the frame with the Skyward Key.

| | Inner opening | With the frame |
|---|---|---|
| Minimum | 2 wide, 3 high | 4 x 5 |
| Maximum | 21 wide, 21 high | 23 x 23 |

The portal can face either horizontal axis. The first one you light earns the *Halo of the Heavens* advancement.

## Return portals

Portals link like Nether portals, at a 1:1 scale: you come out at the same coordinates on the other side.

- If a Halo Portal already exists within about 128 blocks of the destination, you arrive there.
- Otherwise a small frame is generated for you. In the Upfall it is placed on an island, never over the void; if no suitable island is found nearby, a small Pearlstone platform is built instead.
- In the Overworld the return portal is built on the surface.

> Because coordinates map 1:1, a portal at the top of a sky tower sends you to the equivalent spot above the Upfall. Choose where you light it with that in mind.
