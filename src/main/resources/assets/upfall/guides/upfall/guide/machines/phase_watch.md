# Phase Watch

<ItemImage id="phase_watch" scale="4" float="right" />

The **Phase Watch** is a pocket clock for the Chronospire. While you hold it, it shows the current phase and the time left before the next one in the action bar. The item icon also changes with the phase (dawn, noon, dusk, midnight).

## Crafting

Smith a Clock, a <ItemLink id="kairite_gear" /> and a [Phase Watch Blueprint](index.md).

<RecipeFor id="phase_watch" />

## Using it

Hold it in your main hand or off hand. The display refreshes once a second.

The watch only picks up the Chronospire's signal in the Upfall. Anywhere else it reads **No signal**.
